# 🎟️ Chasseur de Concours

Agent qui repère **3 fois par jour** les meilleurs jeux concours gratuits sur 5 sites français,
écarte les petits lots et les doublons, et les classe dans un tableau de bord consultable sur téléphone.

👉 **Tableau de bord : https://martin51188.github.io/Concours-/**

La recherche tourne toute seule grâce à GitHub Actions (`.github/workflows/chasse.yml`).
La participation reste manuelle (les règlements annulent les participations faites par un robot) :
le tableau de bord ouvre le concours, tu remplis (préremplissage Safari / bouton ✍), tu valides.

Version PC : voir `LISEZ-MOI.txt` (`Lancer.bat`).
